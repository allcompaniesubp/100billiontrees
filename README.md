# 200 Billion Trees

A global tree-planting, protection and ecosystem-restoration movement initiated by Entire Space Absolute Foundation.

**Founder:** Dr Ravi Prasad Ch

## Mission

Bring individuals, families, schools, universities, NGOs, businesses, institutions and communities together to plant ecologically suitable trees, protect biodiversity and monitor long-term survival.

## Current status

This repository contains the initial public-facing Next.js foundation and responsive homepage. The progress counters are intentionally labelled as targets or empty verified records. Country cards are illustrative previews, not a complete country directory or verified country reports.

## Local development

Requirements: Node.js 20.9+ and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Production build:

```bash
npm run build
```

## Planned phases

1. Global country and territory directory, SDG alignment and transparent dashboard.
2. Secure accounts, planting submissions, media uploads and Tree Passport.
3. Expert-reviewed native species and regional suitability guidance.
4. Verifier workflows, administrator-only certificates and QR validation.
5. Coordinator applications, organisation registration and event management.
6. Nursery marketplace and donations, subject to legal and provider approval.
7. Internationalisation, geospatial reporting and long-term survival monitoring.

## Environmental integrity

Reported planting, evidence-reviewed planting, independently verified planting and surviving trees are separate measures. A 30–60-day photograph is an early follow-up, not proof of permanent survival. Planting recommendations must be locally appropriate and avoid damage to naturally open ecosystems.

## Governance and safety

No government or UN endorsement is implied. External data must be used under its licence and terms. Payment processing, paid APIs, fundraising and production deployment require separate approval.
